- Parent `transferOwnership()` remains — initiates 2-step transfer; `acceptOwnership` is overridden to clear pending timelocks

### UUPSUpgradeable (lib/)

- CoveredVaultAdmin overrides: `_authorizeUpgrade()` — implements timelocked upgrade with `pendingImplementation` match
- Parent `upgradeToAndCall()` is public — the `_authorizeUpgrade` override is the ONLY gate

### AccessControlDefaultAdminRulesUpgradeable (lib/)
- **PARENT_CONDITIONAL_OVERRIDE**: YES
- CoverPool overrides: `grantRole()`, `revokeRole()` — restricts both to DEFAULT_ADMIN_ROLE only
- Parent has more permissive logic (role admins can grant/revoke their sub-roles)

### ERC20Upgradeable (lib/ via ERC4626Upgradeable)
- **PARENT_CONDITIONAL_OVERRIDE**: YES
- CoveredVaultWrapper overrides: `_update()` — blocks transfers between non-zero addresses (soulbound shares)
