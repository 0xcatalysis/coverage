| premiumRatePerSecond | CoveredVaultStorage | uint256 | setPremiumRate() + executePremiumRate() | 0 ≤ x ≤ 15,854,895,991 (MAX_PREMIUM_RATE_PER_SECOND ≈ 50%/yr) | Timelocked (OPERATIONAL_DELAY=2h) |

### ⚠️ Deductible/MaxCoverable Constraint Analysis
- `setDeductibleBps(newBps)` validates: `newBps < BPS_DENOMINATOR (10000)` — but does NOT check `newBps < maxCoverableLossBps`
- `executeDeductibleBps()` validates: `newBps < maxCoverableLossBps` — checked at execution time
- `setMaxCoverableLossBps(newBps)` validates: `newBps > 0 && newBps <= BPS_DENOMINATOR`
- `executeMaxCoverableLossBps()` validates: `newBps > deductibleBps` — checked at execution time
- **Cross-constraint note**: Both checks happen at execute time, not propose time. If owner proposes both simultaneously (lower maxCoverable + higher deductible), execution order matters.

## Key Invariants (Expected)

1. `totalPremiumLiability ≤ _morphoValue()` — enforced by `_liabilityHeadroom` cap in `_accruePremium`
2. `deductibleBps < maxCoverableLossBps` — enforced at execute time for both setters
3. `platformFeeBps + poolFeeBps ≤ 10000` — enforced in `distributePremium`
4. `depositCap = coverageLimit * 10000 / maxCoverableLossBps` — maintained by onPolicyBound and executeMaxCoverableLossBps
5. `sum(userPrincipal[u]) == totalPrincipal` — maintained by _deposit (+=) and _withdraw (-=)
6. `sum(userMorphoShares[u]) ≈ IVaultV2(morphoVault).balanceOf(address(this))` — maintained but may accumulate rounding dust
