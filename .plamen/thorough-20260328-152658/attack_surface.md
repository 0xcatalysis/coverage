## External Dependencies

### 1. Morpho V2 Vault (IVaultV2)
- **Type**: ERC-4626 vault (external protocol)
- **Interaction points**:
  - `IVaultV2(morphoVault).deposit(assets, address(this))` — CoveredVaultWrapper.sol:124
  - `IVaultV2(morphoVault).redeem(shares, address(this), address(this))` — CoveredVaultWrapper.sol:563
  - `IVaultV2(morphoVault).convertToAssets(shares)` — CoveredVaultAccrual.sol:140, CoveredVaultWrapper.sol:491
  - `IVaultV2(morphoVault).balanceOf(address(this))` — CoveredVaultAccrual.sol:140, CoveredVaultAdmin.sol:173,207, CoveredVaultWrapper.sol:495,543
  - `IVaultV2(morphoVault).asset()` — CoveredVaultWrapper.sol:89
- **Token nature**: ERC-4626 shares (ERC-20 compliant)
- **Return-value tokens**: Morpho shares on deposit, underlying assets on redeem
- **Side effects**: Morpho V2 vault may have gates/caps, supply caps, fee on redeem, guardian-controlled pause
- **State coupling**: CoveredVaultWrapper caches `lastKnownMorphoValue` as fallback if Morpho reverts

## [ELEVATE] Tags

### [ELEVATE: PROXY_STORAGE]
- **All UUPS upgradeable contracts**: CoverPoolFactory, PolicyManager, ClaimManager, PremiumCollector, PremiumManager, SpecRegistry, Swapper, CoveredVaultWrapper
- CoverPool uses minimal proxy clones (not UUPS but inherits storage layout)
- CoveredVaultWrapper has complex multi-inheritance storage layout declared in CoveredVaultStorage

### [ELEVATE: SINGLE_MAPPING_PER_USER]
- `mapping(address => uint256) userPrincipal` — CoveredVaultStorage.sol:86
- `mapping(address => uint256) userPremiumDebt` — CoveredVaultStorage.sol:117
- `mapping(address => uint256) userMorphoShares` — CoveredVaultStorage.sol:122
- These track per-user state with no nonce/epoch key — susceptible to state confusion on redeposit

### [ELEVATE: ASYMMETRIC_DEPOSIT_WITHDRAW]
- CoveredVaultWrapper._deposit vs _withdraw: deposit adds to principal linearly; withdraw deducts premium, computes insurance, interacts with ClaimManager — SIGNIFICANT asymmetry
- deposit path: approve→deposit Morpho→track shares+principal→mint wrapper shares
- withdraw path: compute premium→burn wrapper→update debts→redeem Morpho→compute insurance→claim insurance→transfer

### [ELEVATE: ASSEMBLY_BLOCKS]
- CoveredVaultWrapper.sol:638 `assembly { tstore(slot, value) }` — transient storage write
- CoveredVaultWrapper.sol:642 `assembly { value := tload(slot) }` — transient storage read
- Used for PENDING_CLAIM_AMOUNT_SLOT, ACTUAL_OUT_SLOT, SKIP_INSURANCE_SLOT

### [ELEVATE: EIP712_SIGNATURES]
- CoverPool uses EIP-712 signed quotes: ECDSA.recover for quote signature verification
- Signature verified in _verifyQuote → QUOTE_SIGNER_ROLE check

### [ELEVATE: CALLBACK_PATTERN]
- ClaimManager → ISpec.evaluate() → CoveredVaultWrapper.evaluate() (re-enters wrapper in view context during fileClaim)
- PolicyManager → IBindPolicyHook.onPolicyBound() → CoveredVaultWrapper.onPolicyBound()

### [ELEVATE: EXTERNAL_LOW_LEVEL_CALL]
- Swapper.sol:311 `swapTarget.call(swapCalldata)` — arbitrary external call to whitelisted DEX targets
- Swapper.sol:330 `recipient.call{value: amountOut}("")` — ETH transfer to recipient

### [ELEVATE: FEE_ON_TRANSFER_RISK]
- ClaimManager processes arbitrary collateral tokens from slashing — fee-on-transfer tokens would cause accounting mismatch in `_processCollateral`

## Trust Assumptions

| Actor | Trust Level | Capabilities |
|-------|------------|--------------|
| DEFAULT_ADMIN_ROLE (core contracts) | FULLY_TRUSTED | Upgrade contracts, set all parameters, pause/unpause, recover tokens |
| CREATOR_ROLE (CoverPoolFactory) | SEMI_TRUSTED | Create pools, set implementations, set dependency addresses |
| QUOTE_SIGNER_ROLE (CoverPool) | SEMI_TRUSTED | Sign EIP-712 quotes (determines coverage terms) |
| SWAP_MANAGER_ROLE (Swapper) | SEMI_TRUSTED | Configure swap routes and targets |
| SWAP_EXECUTOR_ROLE (Swapper) | SEMI_TRUSTED | Execute swaps (intended to be ClaimManager) |
| PREMIUM_COLLECTOR_ROLE (PremiumManager) | SEMI_TRUSTED | Distribute premiums (intended to be PremiumCollector) |
| CoverPool curator (owner()) | SEMI_TRUSTED | Bind policies for requests, approve claims, set pool fees |
| CoveredVaultWrapper owner | SEMI_TRUSTED | Timelocked parameter changes (premium rate, deductible, max loss, upgrade), Morpho gate, rescue tokens |
| ClaimManager → fileClaim caller | AUTH_GATED | Must be metadata.claimer (CoveredVaultWrapper sets itself as claimer) |
| distributeBatch caller | PERMISSIONLESS | Can trigger premium distribution for any registered vault |
| Morpho V2 vault | EXTERNAL_TRUSTED | Assumed to correctly implement ERC-4626; gateway/cap behavior can block CoveredVaultWrapper |

## Cross-Contract Call Graph (Critical Paths)

### Claim Payout Path
```
CoveredVaultWrapper._withdraw()
  → _claimInsurance()
    → ClaimManager.fileClaim()
      → _evaluateSpec()
        → CoveredVaultWrapper.evaluate() [callback into wrapper, view]
      → _capAndExecutePayout()
        → SlashingManager.previewSlashing()
        → _computeVaultSlashes()
          → Swapper.quoteSwap() [per vault]
        → SlashingManager.executeSlashing()
        → _processCollateral()
          → Swapper.executeSwap() [per collateral token]
            → UniswapV3Adapter.swap() [or other whitelisted target]
        → _transferToken() [to beneficiary = CoveredVaultWrapper]
```

### Policy Binding Path
```
CoverPool.bindPolicyForRequest()
  → PolicyManager.bindPolicy()
    → StakeManager.getCommitteeVaults/TokenStakes()
    → ChainlinkPriceFeed.getUSDValue() [per token]
    → IBindPolicyHook.onPolicyBound()
      → CoveredVaultWrapper.onPolicyBound() [sets depositCap]
```

### Premium Distribution Path
```
PremiumCollector.distributeBatch()
  → _distribute()
    → IERC4626(vault).redeem() [redeems shares to underlying]
    → IERC20.safeTransfer() [to premiumManager]
    → PremiumManager.distributePremium()
      → ICoverPool.poolFeeBps/owner/feeRecipient()
      → IERC20.safeTransfer() [platform fee → treasury]
      → IERC20.safeTransfer() [pool fee → feeRecipient]
      → RewardsManager.distributeRewards() [restaker share]
```
