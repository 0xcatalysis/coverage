## Detailed Pattern Analysis

### TEMPORAL Patterns
1. **Premium accrual engine**: `lastPremiumAccrualTime` + `premiumRatePerSecond` × elapsed seconds — CoveredVaultAccrual
2. **Active window calculation**: `_activeElapsedFrom(checkpoint)` — complex time-windowing with policy start/maturity + gateGracePeriod extension
3. **Timelocked parameter changes**: OPERATIONAL_DELAY (2h), STANDARD_DELAY (2d), UPGRADE_DELAY (7d) — CoveredVaultAdmin
4. **Distribution interval**: `distributeInterval` (default 86400s) controls minimum time between vault distributions — PremiumCollector
5. **Coverage window**: `startTime ≤ block.timestamp ≤ maturityTime` for claim eligibility — ClaimManager
6. **Quote expiration**: `expirationTime ≥ block.timestamp` — CoverPool

### ORACLE Patterns
1. **Chainlink price feed**: `getUSDValue(token, amount)` used in PolicyManager.bindPolicy to compare totalStakeUSD vs coverageLimitUSD
2. No staleness checks visible in PolicyManager — relies on IChainlinkPriceFeed implementation
3. No fallback oracle mechanism

### DEX_INTEGRATION Patterns
1. **Swapper**: Generic swap routing with whitelisted targets + stored routes
2. **QuoteSwap**: Used for pre-swap estimation (slippage calculation in ClaimManager)
3. **Balance-diff verification**: Swapper._performSwap measures output via balance difference (robust against return-value manipulation)
4. **Slippage protection**: ClaimManager inflates slash amounts to compensate for anticipated DEX slippage, capped at maxSwapSlippageBps

### ERC4626 Patterns
1. **CoveredVaultWrapper**: Full ERC-4626 with custom deposit/withdraw that track principal + Morpho shares per user
2. **Soulbound shares**: `_update` blocks transfers between non-zero addresses
3. **Decimals offset**: `_decimalsOffset() = 6` for inflation attack protection
4. **Deposit cap**: Set by onPolicyBound, enforced in maxDeposit/maxMint
5. **PremiumCollector**: Uses standard ERC-4626 `redeem` and `balanceOf` on registered vaults

### BALANCE_DEPENDENT Patterns
1. **CoveredVaultWrapper._claimInsurance**: Uses `balanceBefore/balanceAfter` diff to determine insurance payout
2. **Swapper._performSwap**: Uses `balanceBefore/balanceAfter` diff to determine swap output
3. **CoveredVaultAccrual._morphoValue**: `convertToAssets(balanceOf(this))` — total Morpho value
4. **PremiumCollector._distribute**: `IERC4626(vault).balanceOf(address(this))` for share count

### SIGNATURE Patterns
1. **EIP-712 quote signing**: CoverPool uses `_hashTypedDataV4(policyCommit)` + `ECDSA.recover(digest, signature)`
2. **Quote typehash**: Includes pool, policyId, coverageLimit, basePremium, specId, termsHash, beneficiary, startTime, maturityTime, expirationTime
3. **Signer validation**: `hasRole(QUOTE_SIGNER_ROLE, signer)`
